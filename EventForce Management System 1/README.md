# EventForce — Verdant Edition
Same folder-by-folder structure, new visual identity.

- Palette: deep teal #08302b · cream #fbf7f0 · coral #ff6b4a · lime #b8f35a
- Fonts: Fraunces (headings, serif) + DM Sans (body)
- Shapes: pill buttons, 20px cards, soft warm borders, teal gradient sections

To change the theme again: edit the `VERDANT THEME` block at the bottom of each `style.css`
(CSS variables in :root), and the `tailwind.config` block in `final output/` and `project 2/`.
